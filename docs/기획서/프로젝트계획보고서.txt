1. 추진 배경 및 목적
추진 배경: 냉장고에 다양한 식재료가 있음에도 불구하고 보유하고 있는 재료로 어떤 음식을 만들 수 있는지 쉽게 떠올리기 어렵고, 식재료의 유통기한을 제대로 관리하지 못하여 음식물을 폐기하는 경우가 발생한다.

특히 소비자는 구매한 식재료의 정확한 소비기한을 알지 못하는 경우가 많다. 포장 식품과 달리 채소, 과일, 정육 등 신선 식재료는 소비기한이 표시되어 있지 않은 경우가 많아, "어제 산 양배추는 언제까지 먹을 수 있는가"와 같은 기본적인 판단조차 어렵다. 또한 요리 후 사용한 식재료를 매번 직접 정리해야 하므로 냉장고 정보가 실제 상태와 쉽게 달라진다.

이를 해결하기 위해 사용자가 냉장고에 보유하고 있는 식재료를 직접 입력하거나 사진을 업로드하여 등록하고, AI를 활용하여 등록된 식재료를 기반으로 적절한 레시피를 추천받을 수 있는 웹 서비스를 개발하고자 한다.

또한 식재료의 유통기한을 관리하고, 소비기한이 표시되지 않은 식재료는 앱이 권장 소비기한을 안내하며, 소비기한이 임박한 식재료를 우선적으로 활용할 수 있도록 레시피를 추천하여 식재료의 효율적인 소비를 돕고자 한다.

추진 목적: 냉장고에 보관된 식재료와 유통기한을 체계적으로 관리하고, 사용자가 보유한 식재료를 최대한 활용할 수 있는 레시피를 AI를 통해 추천함으로써 식재료를 효율적으로 소비하고 음식물 폐기를 줄이는 것을 목적으로 한다.

2. 프로젝트 개요
주요 내용: 본 프로젝트는 사용자의 냉장고에 보관된 식재료를 등록하고 관리하며, 등록된 식재료를 기반으로 AI가 레시피를 추천하는 웹 서비스이다.

사용자는 식재료를 직접 입력하거나 사진을 업로드하여 등록할 수 있으며, 등록된 식재료의 종류와 유통기한을 관리할 수 있다.

소비기한이 표시되지 않은 식재료는 사용자가 날짜를 직접 입력하지 않아도 앱이 식재료별 권장 보관 기간을 기준으로 소비기한을 자동으로 안내한다. 사용자는 안내된 소비기한을 그대로 사용하거나 필요한 경우 직접 수정할 수 있다.

AI 레시피 추천 기능은 기본적으로 소비기한이 임박한 식재료를 활용한 요리부터 우선 추천하며, 사용자가 보유하고 있는 식재료만으로 만들 수 있는 음식을 우선적으로 추천하고, 보유한 식재료만으로 조리하기 어려운 경우 부족한 추가 재료를 함께 안내한다.

사용자가 추천받은 레시피로 요리를 완료하면 해당 레시피에 사용된 식재료를 냉장고에서 자동으로 차감하여, 별도의 수동 정리 없이 냉장고 정보가 실제 상태와 일치하도록 유지한다.

회원가입 및 로그인 기능을 제공하여 사용자별로 냉장고 식재료와 유통기한 정보를 관리할 수 있도록 구현한다.

기대 효과: 냉장고에 보관된 식재료를 효율적으로 소비할 수 있다.

유통기한이 임박한 식재료를 우선적으로 활용하여 식재료의 폐기를 줄이는 데 도움을 줄 수 있다.

사용자가 소비기한을 알지 못하는 식재료도 앱이 권장 소비기한을 안내하므로, 별도로 검색하지 않고도 식재료의 보관 가능 기간을 쉽게 파악할 수 있다.

요리 후 사용한 식재료가 자동으로 차감되어 사용자의 관리 부담을 줄이고 냉장고 정보의 정확도를 유지할 수 있다.

사용자가 보유한 식재료를 활용하여 만들 수 있는 음식에 대한 아이디어를 쉽게 얻을 수 있다.

사용자가 직접 레시피를 검색하는 데 필요한 시간과 노력을 줄일 수 있다.

AI를 활용하여 사용자의 식재료 상황에 맞는 레시피를 제공함으로써 개인 맞춤형 식생활 관리에 도움을 줄 수 있다.

3. 추진 범위 및 수행 방안
추진 범위:
1. 회원가입 및 로그인
* 회원가입
* 로그인 및 로그아웃
* 사용자별 냉장고 데이터 관리

2. 냉장고 식재료 관리
* 식재료 직접 입력
* 식재료 사진 업로드
* 식재료 등록, 수정 및 삭제
* 현재 보유하고 있는 식재료 조회
* 요리 완료 시 레시피에 사용된 식재료 자동 차감
* 차감 전 사용 재료 및 수량 확인 후 수정 가능

3. 유통기한 관리
* 식재료별 유통기한 등록
* 소비기한이 표시되지 않은 식재료의 권장 소비기한 자동 안내 (식재료별 권장 보관 기간 기준)
* 자동 안내된 소비기한의 사용자 수정 기능
* 유통기한 조회 및 관리
* 유통기한이 임박한 식재료 확인
* 유통기한 정보를 AI 레시피 추천에 활용

4. AI 레시피 추천
* 사용자가 보유한 식재료 정보 전달
* 소비기한이 임박한 식재료를 활용한 요리를 기본 우선순위로 추천
* 보유 식재료만으로 만들 수 있는 레시피 우선 추천
* 부족한 재료가 있는 경우 추가로 필요한 재료 안내
* 레시피에 필요한 재료 및 조리 방법 제공
* 요리 완료 처리 기능 제공 (식재료 자동 차감과 연동)

5. 웹 페이지 구현
* 로그인 및 회원가입 화면
* 냉장고 식재료 관리 화면
* 식재료 등록 화면 (권장 소비기한 자동 표시 포함)
* 유통기한 관리 화면
* AI 레시피 추천 화면
* 레시피 상세 화면 (요리 완료 및 사용 재료 차감 확인 포함)

수행 방안: 백엔드는 Spring Boot를 기반으로 개발하며 회원 관리, 식재료 관리, 유통기한 관리 및 AI 레시피 추천을 위한 서버 기능을 구현한다.

프론트엔드는 Thymeleaf를 활용하여 Spring Boot와 연동하고 사용자가 식재료를 등록하고 냉장고에 보관된 식재료와 유통기한을 확인할 수 있도록 웹 페이지를 구현한다.

데이터베이스는 MySQL 또는 PostgreSQL을 후보로 선정하여 프로젝트의 요구사항과 개발 환경을 고려한 후 최종적으로 결정한다.

권장 소비기한 안내 기능은 식재료별 권장 보관 기간(냉장/냉동 기준 일수)을 데이터베이스에 사전 구축하고, 식재료 등록일에 해당 보관 기간을 더하여 소비기한을 자동으로 산출하는 방식으로 구현한다. 사전 구축되지 않은 식재료는 AI를 활용하여 권장 보관 기간을 안내받는다.

AI 기능은 OpenAI API 등의 외부 AI API 사용을 검토하며, 사용자의 냉장고에 등록된 식재료와 유통기한 정보를 AI에 전달하여 적절한 레시피를 추천받는 방식으로 구현한다. 이때 소비기한이 임박한 순서대로 식재료 정보를 전달하고, 임박 식재료를 활용한 레시피를 우선 추천하도록 요청한다.

식재료 자동 차감 기능은 사용자가 레시피 상세 화면에서 요리 완료를 선택하면 레시피에 사용된 식재료와 수량을 보여주고, 사용자가 확인한 후 냉장고 정보에서 해당 수량을 차감하는 방식으로 구현한다. 수량이 모두 소진된 식재료는 냉장고 목록에서 제외한다.

사진을 통한 식재료 등록 기능은 이미지에서 식재료를 인식한 후 사용자가 인식 결과를 확인하고 필요한 경우 수정할 수 있도록 구현한다.

배포는 AWS 사용을 검토 중이며, 프로젝트 개발이 완료된 후 실제 웹 서비스 형태로 배포할 수 있도록 구성한다.

전체적인 개발 과정은 요구사항 분석, 화면 및 데이터베이스 설계, 백엔드 개발, 프론트엔드 개발, AI 기능 연동, 통합 테스트, 오류 수정 및 배포 순으로 진행한다.

6. 예상 이슈 및 대응 계획
예상 이슈:
AI가 사용자가 보유하지 않은 식재료를 활용한 레시피를 추천하거나, 사용자가 입력한 식재료와 관계없는 레시피를 추천할 가능성이 있다.
대응 계획:
AI에게 사용자가 보유하고 있는 식재료 정보를 명확하게 전달하고, 보유 식재료와 추가로 필요한 식재료를 구분하여 응답하도록 프롬프트를 구성한다. 또한 AI의 응답 형식을 일정하게 유지할 수 있도록 구조화된 데이터 형식을 활용하는 방법을 검토한다.

예상 이슈:
사용자가 식재료의 유통기한을 잘못 입력할 가능성이 있다.
대응 계획:
유통기한 입력 형식을 제한하고 날짜에 대한 기본적인 유효성 검사를 적용한다. 또한 유통기한이 임박한 식재료를 별도로 표시하여 사용자가 쉽게 확인할 수 있도록 한다.

예상 이슈:
앱이 안내하는 권장 소비기한은 평균적인 보관 기간을 기준으로 하므로, 구매 시점의 신선도나 보관 상태에 따라 실제 섭취 가능 기간과 차이가 있을 수 있다.
대응 계획:
권장 소비기한은 참고용 안내임을 화면에 명시하고, 사용자가 언제든 직접 수정할 수 있도록 한다. 또한 식재료 상태를 확인한 후 섭취하도록 안내 문구를 함께 제공한다.

예상 이슈:
요리 시 레시피와 다른 양의 식재료를 사용하거나 일부 재료를 생략하여, 자동 차감 결과가 실제 사용량과 다를 수 있다.
대응 계획:
요리 완료 시 바로 차감하지 않고, 사용 재료와 수량을 사용자에게 먼저 보여준 후 수정할 수 있도록 확인 단계를 둔다. 차감 이후에도 냉장고 관리 화면에서 수량을 직접 수정할 수 있도록 한다.

예상 이슈:
사진을 통해 식재료를 등록하는 과정에서 식재료가 정확하게 인식되지 않을 가능성이 있다.
대응 계획:
사진 인식 결과를 바로 저장하지 않고 사용자가 인식 결과를 확인하고 수정할 수 있는 과정을 추가한다. 이를 통해 잘못 인식된 식재료가 냉장고 정보에 등록되는 문제를 최소화한다.

예상 이슈:
AI API를 반복적으로 사용할 경우 API 사용량 및 비용이 증가할 수 있다.
대응 계획:
개발 과정에서 API 호출 횟수를 관리하고 불필요한 반복 호출을 방지한다. 또한 프로젝트 규모에 적합한 AI 모델과 API를 선정하여 비용을 관리한다.

예상 이슈:
AI가 요청할 때마다 서로 다른 형식의 응답을 반환하여 웹 페이지에서 레시피 정보를 표시하기 어려울 수 있다.
대응 계획:
레시피명, 사용 재료, 추가 재료, 조리 방법 등의 응답 형식을 사전에 정의하고 일정한 형식으로 응답하도록 AI를 구성한다.

예상 이슈:
프로젝트 기간 내에 모든 기능을 구현하기 어려울 수 있다.
대응 계획:
식재료 등록, 유통기한 관리, AI 레시피 추천을 핵심 기능으로 설정하여 우선적으로 개발한다. 이후 개발 일정에 따라 사진 기반 식재료 인식과 같은 추가 기능을 구현하며, 일정이 부족할 경우 핵심 기능을 우선적으로 완성한다.
