# 단일 HTML 데모

`요리조리_데모_v9.html` 파일 하나를 브라우저로 열면 동작 (설치·서버 필요 없음, 데이터는 그 브라우저에만 저장)

> 저장소에는 최신 v9만 업로드 (v3부터 파일 하나가 약 14MB). v1~v8은 팀 드라이브에 보관

| 버전 | 내용 |
|---|---|
| v1 | Figma 기반 데모 화면 |
| v2 | 디자인 개선, PC/모바일 전환, 모바일 프레임 크기 조절 |
| v3 | 실제 재료 인식 모델(v3, 25종) 탑재, 등록 직후 레시피 추천 |
| v4 | 공공데이터 레시피 537건, 레시피 검색·더 보기, 상세 정보 확장 |
| v5 | 스캔 결과에서 직접 추가·후보 표시, 과일 12종 기준표 추가 |
| v6 | 소비기한 수정, 초성 검색, 영수증·주문내역 인식, 레시피 영상, 장보기·최저가 안내 |
| v7 | 요리·버리기 애니메이션, 애니메이션 On/Off |
| v8 | 만든 요리 보관함, 먹기·버리기 애니메이션, 요리 기록·통계 |
| **v9** | 인식 모델 v4(33종), 재료별 인식 기준·헷갈리는 재료 버튼, 여러 장 이어서 스캔, 못 먹는 재료(알레르기) |

- v3부터는 모델(base64)과 레시피가 파일 안에 들어 있어 약 14MB
- 데모는 더 고치지 않고, 이제 `backend/`를 수정

## build/

| 파일 | 설명 |
|---|---|
| `build_v3.py` ~ `build_v9.py` | 앞 버전 HTML에 바뀐 부분만 덧붙여 다음 버전을 만든 스크립트 (만들 때 쓴 경로 그대로라 기록용) |
| `split_demo.py` | 데모 HTML을 Spring의 `templates` · `static/css` · `static/js`로 나누는 스크립트 (v9 → backend 화면을 만들 때 사용) |

```bash
python demo/build/split_demo.py demo/요리조리_데모_v9.html backend/src/main/resources
```

> 다시 실행하면 `templates/`, `static/css/`, `static/js/`의 데모 유래 파일을 **덮어씀.** 그 뒤에 손으로 고친 것이 있으면 실행 금지
> (덮어쓰지 않는 파일 : `static/js/api.js`, `static/js/init.js`, `templates/auth/*`)
